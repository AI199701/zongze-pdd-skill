# 车损决策与保本底线

## R — 原文依据

> 能盈利起链接不用保本，能保本起链接不用微亏，能微亏起链接不用巨亏。但如果不得不用巨损的方式起链接，只用车损，绝不碰货损。……保本的85%是微亏，保本的75%可以理解成一般亏，保本的50%才叫巨亏。

来源：aweme 7579971062294682475（3635 字）、7691664073078918052（3852 字）、7647522055714575467。

## I — 解读

车损是**分级决策**，先定档再谈幅度：

| 档位 | 投产位置 |
|---|---|
| 盈利 | ≥保本 |
| 保本 | =保本 |
| 微亏 | 保本 85–90% |
| 一般亏 | 保本 75–80% |
| 巨亏 | 保本 50% |

一般商家建议把标准上调：**保本 80% 当一般亏、保本 90% 当微亏**。

## A1 — 原案例（口播细节）

- 巨亏起链接时**只用车损、绝不碰货损**。
- 巨亏 → 一般亏：多次优化投产，两天打底沉淀，确认仍保留付费速率后，才小幅加限额。
- 到微亏以上，才开始"一边放限额、一边提投产"。
- 保本附近不算真正车损；车损指离保本很远（85% 以下）。
- 车损幅度过大、临近保本才提投产，会掉量严重，应守住起链接投产底线。

## A2 — 迁移与区分

与「限额」「提投产」构成三角：本能力定"亏多少"，另两者定"怎么放量、怎么提价"。

合成演练：保本 2.8 → 微亏档 2.4–2.5 起链接 → 两天沉淀 → 小额放限额 → 提投产回 2.7+。

## E — 执行契约

- 输入：保本投产、可用车损预算、链接预期。
- 输出：车损档位 + 止损限额 + 观测周期。
- 分支：需巨亏 → 只用车损，设硬止损；两天无付费速率 → 该舍则舍。
- 完成标准：档位、止损线、观测周期三要素齐全。


### 失败分支（if-then）

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 车损起链接断流 | 查限额与节奏是否配合 | 仍断 → 降一档车损 |
| 临近保本提投产掉量 | 守投产底线，延长观测 | 仍掉 → 换链接 |
| 巨亏两天无付费速率 | 该舍则舍 | 不要追加投入 |

## B — 边界

不适用于强价格优势的自然流；巨亏策略需极强资金承受力。

## 口播补充

- 保本 85% 以下才是真车损，保本附近掉量是节奏问题不是车损问题。
- 车损起链接断流，多半是前期没配合限额、没把握节奏，而不是车损本身错。

## 反模式黑名单

- 不要碰货损
- 不要为起链接强行加深车损
- 不要在临近保本时才提投产
- 不要在没有止损线时做巨亏起链接

## 执行检查点

- 🔴 定车损档位前：确认保本投产
- 🛑 两天无付费速率：STOP，放弃该链接
