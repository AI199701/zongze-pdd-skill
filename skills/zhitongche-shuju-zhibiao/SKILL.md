# 直通车数据观测优先级

## R — 原文依据

> 最重要的五项数据指标分别是花费速率、曝光、点击率、转化率和推广曝光占曝光占比。……前期看转化，中期看推广曝光占比，后期看点击率。曝光从初始基数到波动适配，到趋于平稳伴随观测全程。转化占比看短，点击率曝光看长。

来源：aweme 7613748543812591977（4906 字）、7665697406399675306（4953 字）、7637125764643293814（4546 字）。

## I — 解读

数据不是越多越好，而是**按阶段排优先级**：
- **前期**：转化率（=比定价指标）+ 推广曝光占比（=比出价指标）
- **中期**：推广曝光占曝光占比
- **后期**：点击率 / 精泛比例
- **全程**：曝光（量的体现）、花费速率

## A1 — 原案例（口播细节）

- 转化率高 = 比定价比得过同行；推广曝光占比高 = 比出价比得过同行；两者合起来就是**比价机制**。
- 占比达标时，转化率往往跟着占比走 → 这就是"出价弥补定价不足"。
- 高点击率 + 高转化率不一定是好数据：要看曝光与投产组合；低曝光高投产 = 赛道窄；高曝光低投产 = 截流。
- 过高点击率要防专题位无用流量；转化率异常高要查智能优惠券是否过大（会把占比压得过低）。
- 节流后要沉淀 **至少 3 天**再优化，让截流流量沉淀为精度流量。

## A2 — 迁移与区分

与「精泛比例」区别：本能力是观测方法论，后者是机制解释。与「智能优惠券」区别：后者是干扰项排查。

合成演练：新链接 → 先看转化率与占比 → 有量后看占比 → 成型后看点击率与精泛。

## E — 执行契约

- 输入：链接阶段、五项指标当前值。
- 输出：当前阶段第一优先级指标 + 结论 + 一步动作。
- 分支：指标矛盾 → 用平衡变量法找主核心指标；转化率虚高 → 先查智能优惠券。
- 完成标准：给出唯一主指标 + 对应动作。

## B — 边界

不适用于无付费数据的自然流链接；指标口径随平台改版变化。

## 口播补充

- 曝光是"量"、点击率是"质"，有质量保障的前提下曝光才越大越好。
- 长周期看精泛/点击率，短周期看比定价转化率与比出价占比，两套尺子不能混用。
