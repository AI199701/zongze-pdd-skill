# 决策规则速查 — 宗泽PDD实战·拼多多强付费运营全体系（525 条视频口播蒸馏）

| 能力 | 一句话规则 |
|---|---|
| 起链接三阶段与全流程 | 按链接识别→出价识别→付费激活三段推进起链接。 |
| 起链接前的五项准备 | 用五步串行筛选出可起链接的品/价/链接。 |
| 测价与测链接 | 测价控变量、测链接放变量，3%降毛利精筛。 |
| 出价形式选择：成交出价 vs 投产比 | 按品类与阶段选成交出价或投产比，并定方向。 |
| 冷启动出价幅度 | 小幅多次起步，拿不到500曝光转大幅长间隔。 |
| 限额设置与放开节奏 | 按保本偏离决定先提投产还是先放限额。 |
| 车损决策与保本底线 | 盈利>保本>微亏>巨损分级，巨损只用车损。 |
| 提投产节奏与观测 | 每次5-10%、间隔3天、观测3天做赛道取舍。 |
| 错峰与拉扯操作 | 优先错峰切出价形式，无效再拉扯猛降缓升。 |
| 直通车数据观测优先级 | 前期看转化、中期看占比、后期看点击率。 |
| 精泛比例与流量模型 | 精泛循环 + 成交建搜索模型、投产做推荐收割。 |
| 空烧/投产飘黄/被锁异常处理 | 空烧按五因定位，飘黄被锁不急于操作。 |
| 比价、防比价与洗链接 | 比价=比定价+比出价；防比价靠区分底稿与SKU文字。 |
| 裂变与铺货规则 | 单日≤7、一周≤20，按保本投产统一调车筛选。 |
| 定制批发类双出价 | 成交托底+询单为主，客单优先、长间隔大幅度。 |
| 平销 vs 活动流 | 平销为基线，活动是润滑剂非必需品。 |
| 智能优惠券的影响 | 券占比过大会人群偏离、干预出价、扰乱测价。 |
| 全量付费化判断 | 有无价格优势决定自然流/活动还是全量付费。 |
