# 定制批发类双出价

## R — 原文依据

> 第一是出价形式为成交出价加询单为主；第二是出价提高的目标以客单为第一位；第三是出价调整上，建议更长间隔更大幅度调整……第五点就是要理解成交出价的成交目标导向，以及多目标出价以询单为主的双出价体系。

来源：aweme 7689077464853703850。

## I — 解读

定制/批发类拿的是**客群不是单量**：成交出价托底 + 询单出价为主，客单优先，长间隔大幅度调整，高客单时段加价稳人群。

## A1 — 原案例

原文五点：成交+询单双出价、客单第一、长间隔大幅度、内功多 SKU 测试、成交托底不压制询单。

## A2 — 迁移与区分

与标准品出价（追投产/单量）区分。合成演练：客单 800 → 成交托底 + 询单为主，5–7 天调 10–15%，晚 8–10 点加价。

## E — 执行契约

- 输入：客单价、询单成本、竞品内功布局。
- 输出：双出价方案 + 调整节奏 + SKU 布局建议。
- 分支：询单成本过高 → 降询单出价、保成交托底。
- 完成标准：给出双出价数值 + 周期 + 观测指标。

## B — 边界

不适用于低客单标品；不适用于纯自然流定制商家。
