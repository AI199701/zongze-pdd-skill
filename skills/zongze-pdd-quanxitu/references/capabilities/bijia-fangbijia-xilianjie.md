# 比价、防比价与洗链接

## R — 原文依据

> 比价是比定价和比出价两种，不要简单的认为比价只是比定价，出价可以弥补定价的不足。……只要和前期尤其是冷启动过程当中，绝对低价的竞品，区分主图底稿元素和sku主修饰文字，就已经绝对用好了防比价。

来源：aweme 7416320525041028402、7564386183741099318、7444892996476079369、7673481131501651940。

## I — 解读

比价 = **比定价 + 比出价**。防比价的核心是区分"主图底稿元素 + SKU 主修饰文字"，不必神化；洗链接优先级是先洗 SKU、再洗主图，且应先用"车"挽回比价损失。

## A1 — 原案例

原文：过度依赖洗链接与防比价是误区；多级 SKU 定价可比的是每个 SKU 而非链接，可用辅助 SKU 定价或做小而美链接突围。

## A2 — 迁移与区分

与「测价测链接」区别：本能力处理"被比价后的应对"，后者处理"定价前的测试"。合成演练：被低价竞品比价 → 先调出价弥补 → 再洗 SKU → 最后洗主图。

## E — 执行契约

- 输入：竞品价格、当前主图/SKU 结构、比价表现。
- 输出：出价弥补方案 or 洗链接方案（SKU 优先）。
- 分支：出价可弥补 → 不洗链接；不可弥补 → 洗 SKU。
- 完成标准：比价损失收敛或链接完成差异化。

## B — 边界

不适用于有绝对价格优势的商家；洗链接过度会伤权重。
