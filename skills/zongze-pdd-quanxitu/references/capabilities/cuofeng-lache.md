# 错峰与拉扯操作

## R — 原文依据

> 错峰指的是投产比形式前提下，把一天当中花费最差的时间段切到成交出价形式，出价参考过往平均每笔净扣费金额的1.05倍向1.2倍尝试，然后再切回投产比原投产。……不可以使用错峰的商家，或错峰效果连续两次不好的商家才会使用拉扯。

来源：aweme 7566987157191740708（3281 字）、7525426646297070902（3840 字）、7478683213817302323。

## I — 解读

错峰是**时段级出价形式切换**，优先于拉扯；拉扯是**幅度级操作**（猛降缓升），仅在错峰不可用或连续两次无效时启用。

## A1 — 原案例（口播细节）

- 错峰适用：日花费几百到一两千的中腰部链接，效果最好、风险最小。
- 出价倍数：过往平均每笔净扣费 **1.05 → 1.2 倍**；1.05 不够试 1.1，再不够试 1.15。
- 错峰连续两次无效 → 中间隔 **28 天**才能第三次；此时改用拉扯。
- **成交出价形式无法错峰**（错峰必须主推广是投产比），只能拉扯。
- 每笔利润 **< 4 元**不能错峰（一错峰就狂亏），只能拉扯。
- 拉扯时机：**点击率适中**时最合适。
- 比出价问题错峰易解决；比定价问题错峰很难解决，需要新赛道。

## A2 — 迁移与区分

与「提投产」区别：提投产改长期目标，错峰/拉扯改短期节奏。与「出价形式」区别：错峰是在两种形式间临时切换。

合成演练：晚 8–10 点花费最差 → 切成交出价 1.1 倍 → 次日切回原投产比；连续两次无效 → 隔 28 天或转拉扯。

## E — 执行契约

- 输入：分时花费、当前出价形式、每笔利润、错峰历史。
- 输出：错峰时段 + 倍数，或拉扯幅度序列。
- 分支：成交出价形式 / 每笔利润<4 元 → 直接拉扯；错峰两次无效 → 隔 28 天或转拉扯。
- 完成标准：给出可执行时段与倍数/幅度 + 观测点。

## B — 边界

不适用于无法分时调控的账户；拉扯对点击率过低链接无效。

## 口播补充

- 错峰期间本身就是"相对偏高出价"的亏损阶段，所以只适合花费不大、亏得起的链接。
- 错峰周期内要做过 1.05/1.1/1.15 的高低尝试，不能只试一档就放弃。
