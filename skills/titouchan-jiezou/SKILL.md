# 提投产节奏与观测

## R — 原文依据

> 起链接有系统给予一轮二轮三轮的赛道的逐步尝试机会……每次提投产后，多给两天时间，让数据自己表现……提投产都是基于提升投产之后的当下值进行5%到10%每次的操作，切勿混淆原值和当下值的概念。

来源：aweme 7694277038467143588（3479 字）、7478683213817302323（7558 字）、7517638259700370724（3159 字）。

## I — 解读

提投产 = **赛道取舍 + 观测窗口**。每次 5–10%（偏高毛取 10%），间隔约 3 天；提投产后必须做 3 天观测，用"花费速率降幅 vs 提投产幅度"判断是否站住。

## A1 — 原案例（口播细节）

- 观测周期：至少 2 天，建议 **3 天**，稳的商家可拉到 **5 天**。
- 判定标准：**花费速率降幅对比提升投产幅度的 3 倍**（按缓升后的数据算）。
- 典型曲线：第一天掉得狠 → 第二天缓升 → 连续 3–5 天缓升；只要点击率在变化（精度在变），第四天起缓升就按缓升后数据计算。
- 连续两轮掉量 → 赛道站不住，回退换链接。
- 提投产后出问题，可用**错峰**解决，不必急着降回去。

## A2 — 迁移与区分

与「冷启动出价幅度」区别：本能力是"有量后提投产"。与「错峰拉扯」区别：错峰解决短期节奏，提投产改长期目标。

合成演练：投产 2.5 → 提 5% → 观测 3 天 → 花费降幅 < 提投产×3 则继续，否则守底线。

## E — 执行契约

- 输入：当前投产、原值、已观测天数、花费速率。
- 输出：本轮提投产幅度 + 观测窗口 + 站住/回退结论。
- 分支：连续两轮掉量 → 换链接；单轮掉量但点击率在变 → 继续观测到第 4–5 天。
- 完成标准：完成至少两轮"提投产—观测—取舍"闭环。



### 执行步骤

| # | 步骤 | 输入 | 输出 |
|---|---|---|---|
| 1 | 取当前值 | 当前投产、原值、已观测天数、花费速率 | 本轮基准值（当下值，不是原值） |
| 2 | 定幅度 | 毛利水平 | 5% 或 10%（偏高毛取 10%） |
| 3 | 执行提投产 | 基准值 + 幅度 | 新投产值 + 提投产时间 |
| 4 | 观测 3 天 | 每日花费、投产、点击率 | 3 天数据曲线（掉量 / 缓升 / 平稳） |
| 5 | 判定 | 花费降幅、提投产幅度 | 降幅 ≥ 幅度×3 则站住，继续；否则守底线 |
| 6 | 取舍 | 连续两轮结果 | 连续两轮掉量则换链接，否则回步骤 1 |

### 失败分支（if-then）

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 提投产 5% 后掉量 | 观测 3 天再看 | 连续两轮掉 → 换链接 |
| 花费降幅 ≥ 提投产幅度×3 | 赛道站得住，继续提投产 | 降幅不足 → 守底线不加 |
| 提投产不畅 | 用错峰解决 | 仍不畅 → 回退到上一档 |

## B — 边界

不适用于已成型链接的平稳优化（幅度另定）；不适用于无竞品的蓝海。

## 口播补充

- 一次提投产不畅就不敢再提，会让赛道被系统锁定，失去后续匹配与探索机会。
- 提投产幅度基于"提升后的当下值"算，不是基于原值，混用会越提越猛。

## 反模式黑名单

- 不要基于原值算提投产幅度
- 不要一次不畅就不敢再提
- 不要在观测期内频繁改动
- 不要用单日数据判定站住

## 执行检查点

- 🔴 提投产前：确认当前值与保本投产
- 🛑 连续两轮掉量：STOP，换链接

## 参数依据（为什么是这些数）

- 5–10%：幅度太大会被判定异常操作，太小则提不动。
- 花费降幅 ≥ 幅度×3：超过等比例掉量，才说明赛道真的站住。
- 3 天观测：平台数据有滞后，短于 3 天容易把波动当趋势。
