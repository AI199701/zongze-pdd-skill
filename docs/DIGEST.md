## 一、打法总开关

- 有价格优势 → 自然流 + 活动，活动多多益善。
- 无价格优势的中腰部 → **全量付费**，用"推广曝光占曝光占比"替代转化率作定价指标，靠出价弥补定价不足，守投产底线。

## 二、起链接三阶段

1. **链接识别**：周期取决于主图底稿原创度。
2. **出价识别**：5%×4h 拿 500 基础曝光 → 沉淀 3 天 → 无自我放大则 8%×1.5d。
3. **付费激活**：抬过 400/天 付费阈值。

转投产比：≥保本 85%、逐天过渡、限额按预估花费 1.2 倍 → 最终保本 1.25 倍。

## 三、五项准备（准备 ≠ 起链接）

找品（排除难起品）→ 竞品分析（价格集中带）→ 测品测款（偏高投产）→ 测定价（3% 降毛利精筛）→ 测链接（主图/SKU 裂变）。

内功中**定价权重最高**，远大于主图、标题、SKU 布局。

## 四、测价 vs 测链接

- **测价**：除价不同，其余尽量相同。
- **测链接**：除价相同，其余尽量不同。
- 3×3 裂变可一次完成两步。
- 精筛 3% 降毛利，花费明显上升即完成；出价是否同步调，看投产有无让渡空间。

## 五、出价形式

- 成交出价买**精度**（转化率第一），投产比买 **GMV**。
- 起链接用成交出价托精度，成型后转投产比。
- 成交出价注意**低客单集中**与 **SKU 配置**，防止"超高出价才能跑动"。
- 有成交出价精度托底的链接，后期错峰更有效。
- 定制批发 → 长期成交出价 + 询单为主双出价。

## 六、限额

按投产位置分档：保本 70% 以下 100–150；保本 85% 250–300；保本附近 400+。放开幅度**由小变大**；真实限额是实际花费，设置值只是手段。

## 七、车损

| 档位 | 投产位置 |
|---|---|
| 微亏 | 保本 85–90% |
| 一般亏 | 保本 75–80% |
| 巨亏 | 保本 50% |

一般商家建议上调：保本 80% 当一般亏、保本 90% 当微亏。巨亏时**只用车损、绝不碰货损**。

## 八、提投产

每次 5–10%，间隔约 3 天；提投产后观测 3 天（稳的 5 天），用"花费降幅 vs 提投产×3"判定。第一天掉、第二三天缓升属正常，只要点击率在变就按缓升后数据算。

## 九、错峰与拉扯

- **错峰**：投产比形式下，把花费最差时段切成交出价（净扣费 1.05–1.2 倍），再切回。
- 连续两次无效 → 隔 28 天或转拉扯。
- 成交出价形式、每笔利润 <4 元 → 只能拉扯。
- 拉扯时机：点击率适中。

## 十、数据观测优先级

五项：花费速率、曝光、点击率、转化率、推广曝光占曝光占比。
- 前期看转化 + 占比，中期看占比，后期看点击率/精泛，曝光全程。
- 转化率=比定价指标，占比=比出价指标，合起来就是比价机制。
- 节流后沉淀 ≥3 天再优化。

## 十一、精泛比例与流量模型

精准托底带来泛流量，泛流量沉淀回精准，形成循环。成交出价建搜索模型，投产比做推荐收割。

## 十二、异常处理

- **空烧**：连续 3 天以上才是绝对空烧；一天空烧不算。
- 处置：加出价降投产 → 裂变重测 → 调 SKU 倍差 → 重测定价。
- 判定拖迟/衰败看**连续两天花费**。
- 投产飘黄不影响实际付费速率；被锁一般最多三天。

## 十三、比价、防比价、洗链接

- 比价 = 比定价 + 比出价，出价可弥补定价不足。
- 防比价：区分主图底稿元素 + SKU 主修饰文字。
- 洗链接：先洗 SKU，再洗主图；先用"车"挽回比价损失。

## 十四、裂变与铺货

单日 ≤7、一周 ≤20。裂变后按各自保本投产统一调车，公平竞争筛出综合最优链接。

## 十五、平销 vs 活动

平销是基线，活动是润滑剂。先做稳平销再接活动，或先活动再开车（考虑流量惯性继承）。

## 十六、智能优惠券

占比过大会导致人群偏离、干预出价（与推广曝光占比成反比）、测价价格带跳动。数据观测中单列"券占当日花费比例"。

## 一句话总结

**先定打法，再走三阶段；准备与起链接分离；出价买精度、投产买GMV；限额分档控速、车损分级止损、提投产按 5–10% 取舍；数据分阶段看，异常先分类；比价靠出价弥补，裂变有额度。**
